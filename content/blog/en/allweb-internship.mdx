My internship at Allweb was where I went from learning to actually building — real products, real users, real deadlines.

> **TL;DR:** Joined Allweb as a Frontend Intern in 2023. Shipped HRM mobile UI in React and a full-stack Digital Approval System using Next.js, Java Spring Boot, and enterprise tooling. Transitioned to full-time after the internship.

## Getting Started

I joined Allweb as a Frontend Developer Intern in 2023. The team was working on multiple products simultaneously, and I was thrown into the deep end quickly. That was the best thing that could have happened.

## The Projects

### HRM Mobile — React

The first project I contributed to was an **HRM (Human Resource Management) mobile application** built with React. I worked on UI components, form handling, and connecting to backend APIs. It was my first experience building for mobile — the constraints are different, the UX patterns are different, and performance matters in a way that desktop doesn't demand.

### Digital Approval System — Full Stack

The bigger project was a **Digital Approval System** — a workflow platform for managing approvals across departments.

| Layer          | Technology                                     |
| -------------- | ---------------------------------------------- |
| Frontend       | Next.js, TypeScript, ShadCN UI, TanStack Query |
| Backend        | Java Spring Boot, Liquibase                    |
| Auth           | Keycloak (SSO, IAM)                            |
| Messaging      | RabbitMQ (async notifications)                 |
| Workflow       | Camunda (BPMN process engine)                  |
| Infrastructure | Docker                                         |

The approval workflow UI required complex form states, multi-step flows, and real-time status updates. On the backend, I learned how enterprise Java applications are structured — service layers, repositories, DTOs, and the discipline that comes with a strongly-typed backend.

## What I Learned

**Full-stack is a mindset, not just a skill set.** Understanding how the frontend, backend, message queue, and auth layer interact changed how I design components. I stopped thinking in isolation.

**Enterprise tooling is a different world.** Keycloak, RabbitMQ, Camunda — these aren't things you learn from tutorials. You learn them by debugging at 11pm when a workflow isn't triggering correctly.

**TypeScript + Java is a powerful combination.** Strong typing on both ends of the stack means fewer surprises at runtime. The discipline transfers.

## Moving Forward

After the internship, I transitioned to a full-time Frontend Developer role at Allweb. The internship gave me the foundation — the full-time role is where I'm applying it at scale.
