ការធ្វើកម្មសិក្សារបស់ខ្ញុំនៅក្រុមហ៊ុន Allweb គឺជាពេលដែលខ្ញុំបានផ្លាស់ប្តូរពីការរៀនសូត្រ ទៅកាន់ការបង្កើតផលិតផលពិតៗ — ផលិតផលពិត អ្នកប្រើប្រាស់ពិត និងពេលវេលាកំណត់ពិតប្រាកដ។

> **សេចក្តីសង្ខេប (TL;DR):** ចូលរួមជាមួយ Allweb ក្នុងនាមជា Frontend Intern ក្នុងឆ្នាំ 2023។ បានបញ្ចេញ (Ship) HRM mobile UI ដោយប្រើ React និងប្រព័ន្ធ Digital Approval System បែប Full-stack ដោយប្រើ Next.js, Java Spring Boot និង Tools កម្រិត Enterprise។ បានផ្លាស់ប្តូរទៅជាបុគ្គលិកពេញម៉ោង (Full-time) ក្រោយបញ្ចប់កម្មសិក្សា។

## ការចាប់ផ្តើម (Getting Started)

ខ្ញុំបានចូលរួមជាមួយ Allweb ក្នុងនាមជា Frontend Developer Intern នៅឆ្នាំ 2023។ ក្រុមការងារកំពុងអភិវឌ្ឍផលិតផលជាច្រើនក្នុងពេលតែមួយ ហើយខ្ញុំត្រូវបានគេដាក់ឲ្យចូលធ្វើការងារធំៗភ្លាមៗតែម្តង។ នោះគឺជារឿងដ៏ល្អបំផុតដែលបានកើតឡើង។

## គម្រោងនានា (The Projects)

### HRM Mobile — React

គម្រោងទីមួយដែលខ្ញុំបានចូលរួមគឺ **កម្មវិធីទូរស័ព្ទ HRM (គ្រប់គ្រងធនធានមនុស្ស)** ដែលបង្កើតឡើងដោយប្រើ React។ ខ្ញុំបានធ្វើការលើ UI components, ការគ្រប់គ្រង Form, និងការតភ្ជាប់ទៅកាន់ Backend APIs។ នេះជាបទពិសោធន៍ដំបូងរបស់ខ្ញុំក្នុងការបង្កើតកម្មវិធីទូរស័ព្ទ (Mobile app) — វត្ថុបំណងគឺខុសគ្នា, ទម្រង់ UX គឺខុសគ្នា, ហើយល្បឿនដំណើរការ (Performance) គឺជារឿងសំខាន់បំផុតក្នុងកម្រិតមួយដែល Desktop មិនសូវទាមទារ។

### ប្រព័ន្ធអនុម័តឌីជីថល (Digital Approval System) — Full Stack

គម្រោងដែលធំជាងនេះគឺ **Digital Approval System** — ដែលជាប្រព័ន្ធ Workflow សម្រាប់គ្រប់គ្រងការអនុម័តឆ្លងកាត់នាយកដ្ឋានផ្សេងៗ។

| ផ្នែក (Layer)  | បច្ចេកវិទ្យា (Technology)                      |
| -------------- | ---------------------------------------------- |
| Frontend       | Next.js, TypeScript, ShadCN UI, TanStack Query |
| Backend        | Java Spring Boot, Liquibase                    |
| Auth           | Keycloak (SSO, IAM)                            |
| Messaging      | RabbitMQ (async notifications)                 |
| Workflow       | Camunda (BPMN process engine)                  |
| Infrastructure | Docker                                         |

UI នៃដំណើរការអនុម័តនេះ ទាមទារឲ្យមាន Form states ស្មុគស្មាញ, ដំណើរការច្រើនដំណាក់កាល (Multi-step flows), និងការអាប់ដេតស្ថានភាពភ្លាមៗ (Real-time)។ នៅផ្នែក Backend, ខ្ញុំបានរៀនពីរបៀបដែលកម្មវិធី Java កម្រិត Enterprise ត្រូវបានរៀបចំ — Service layers, Repositories, DTOs, និងវិន័យដែលភ្ជាប់មកជាមួយ Backend ដែលប្រើ Strongly-typed។

## អ្វីដែលខ្ញុំបានរៀនសូត្រ (What I Learned)

**Full-stack គឺជាផ្នត់គំនិត (Mindset) មិនមែនគ្រាន់តែជាបណ្តុំជំនាញនោះទេ។** ការយល់ដឹងពីរបៀបដែល Frontend, Backend, Message queue, និង Auth layer ធ្វើការជាមួយគ្នា បានផ្លាស់ប្តូររបៀបដែលខ្ញុំ Design components។ ខ្ញុំលែងគិតតែមួយជ្រុងៗទៀតហើយ។

**Tools កម្រិត Enterprise គឺជាពិភពមួយផ្សេងទៀត។** Keycloak, RabbitMQ, Camunda — របស់ទាំងនេះមិនមែនជាអ្វីដែលអ្នករៀនពីវីដេអូ Tutorials នោះទេ។ អ្នករៀនពីវា តាមរយៈការអង្គុយ Debug ម៉ោង 11 យប់ នៅពេលដែល Workflow មិនព្រមដំណើរការត្រឹមត្រូវ។

**TypeScript + Java គឺជាការរួមបញ្ចូលគ្នាដ៏មានឥទ្ធិពល។** ការប្រើប្រាស់ Strong typing នៅទាំងសងខាងនៃ Stack មានន័យថា នឹងមានបញ្ហាតិចតួចនៅពេល Runtime។ វិន័យក្នុងការសរសេរកូដគឺត្រូវបានផ្សារភ្ជាប់គ្នា។

បន្ទាប់ពីបញ្ចប់កម្មសិក្សា ខ្ញុំបានផ្លាស់ប្តូរទៅជាបុគ្គលិកពេញម៉ោងក្នុងតួនាទី Frontend Developer នៅក្រុមហ៊ុន Allweb។ កម្មសិក្សានេះបានផ្តល់នូវមូលដ្ឋានគ្រឹះដល់ខ្ញុំ — រីឯតួនាទីជាបុគ្គលិកពេញម៉ោង គឺជាកន្លែងដែលខ្ញុំកំពុងអនុវត្តវាក្នុងទំហំធំជាងមុន។
